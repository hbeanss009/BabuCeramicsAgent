"My specific recommendation: Supabase (PostgreSQL under the hood)
Here's why it's a great fit for each part of your system:
For the catalog — PostgreSQL gives you clean relational tables for items, collections, pricing, and artists. Your tools (pricing, collection, recommendation, item inquiry, etc.) all map naturally to simple SQL queries against these tables.
For the agent tools — Supabase exposes a REST API and client libraries out of the box, so each tool can query the catalog without you needing to build a custom API layer from scratch.
For the email/conversation flow — Supabase also has a conversations or threads table you can add to log queries and replies, which is useful for context if you ever want the agent to remember prior exchanges.
For recommendations — Supabase supports pgvector, a PostgreSQL extension for vector embeddings. This is perfect if you later want semantic/AI-powered recommendations (e.g. "find items similar to this one").
Free tier is generous — more than enough for a project of this size."
